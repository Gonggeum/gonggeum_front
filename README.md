# 공금이 프론트엔드

26-2 창업동아리 프로젝트 팀 공금이의 프론트엔드 저장소입니다.

React · TypeScript · Vite · React Router · TanStack Query · MSW를 사용하는 공금이 모의 앱입니다. 화면 배치는 기능 검증용입니다.

## 실행

Node.js 24에서 확인했습니다. PowerShell에서 프로젝트 폴더를 열고 실행합니다.

```powershell
npm.cmd ci
npm.cmd run dev
```

터미널에 표시된 localhost 주소를 엽니다. 브라우저가 localhost에서 MSW 서비스 워커를 등록할 수 있어야 합니다.

## 개발 검증 루프

1. 화면설계서나 API 명세에서 이번에 바꿀 동작과 인수 조건을 한 가지 정한다.
2. 재현 가능한 브라우저 테스트를 추가하고 수정 전 기대한 지점에서 실패하는지 확인한다.
3. 화면, API 호출, 모의 응답에서 필요한 범위만 수정한다.
4. 검증 명령으로 린트, 타입 검사·빌드, Chrome 회귀 테스트를 모두 실행한다. 통과한 범위와 남은 계약을 기록한다.

```powershell
npm.cmd run verify
```

검증에는 설치된 Chrome을 사용한다. Edge를 사용하려면 PowerShell에서 `$env:GONGGEUMI_BROWSER_CHANNEL = 'msedge'`를 지정한다. 테스트는 빌드 결과를 별도 로컬 포트에서 열고 새 브라우저 컨텍스트에서 실행한 뒤 서버와 브라우저를 종료한다. 빌드가 이미 있는 경우 브라우저 검증만 `npm.cmd run test:e2e`로 다시 실행할 수 있다. 테스트 데이터와 API는 MSW로 제공한다.

첫 반복에서는 화면 02의 조회 조건을 URL과 동기화했다. 검색·유형과 소계가 새로고침 뒤에도 유지되고, 초기화하면 URL과 전체 소계가 복원되는지 확인한다.

## 데모 데이터

- 총무 계정에서 행사 운영 장부를 열면 초기 공금 200,000원이 표시됩니다. 같은 팀에 조회용 마감 장부도 있습니다.
- 참여자 계정으로 본인 지출의 작성·수정·삭제 권한을 확인할 수 있습니다. 목표 예산 저장은 총무 계정에서 가능합니다.
- 팀 없음, 장부 없음 계정으로 각 빈 상태를 확인할 수 있습니다.
- 장부 선택 화면에서 초대 코드 `gonggeumi-demo-invite`를 조회할 수 있습니다. 초대 딥링크 형식은 `/#invite_token=gonggeumi-demo-invite`입니다.
- 데이터를 초기화하려면 브라우저 개발자 도구의 Application → Storage에서 해당 localhost 사이트 데이터를 지우고 새로고침합니다. 데모 장부, 모의 세션, 마지막 장부 기록이 함께 초기화됩니다.

화면 번호, 적용 API, 검증 범위는 [작업 결과](공금이_프론트엔드_첫_구현_결과.md)에 기록했습니다.
